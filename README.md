# 할 일 관리

하루 10~20개 정도의 할 일을 관리하는 개인용 웹 앱입니다. 서버나 설치 없이 브라우저에서 바로 실행되고, 새로고침해도 데이터가 유지됩니다. 프레임워크와 빌드 도구 없이 순수 JavaScript로 만들었습니다.

## 주요 기능

- 할 일 추가 / 수정 / 삭제 (제목 클릭으로 바로 수정, 삭제 후 5초간 실행 취소)
- 완료 체크
- 카테고리 분류: 업무 / 개인 / 공부, 카테고리별 필터
- 날짜별 목록: 전날 / 오늘 / 다음날 이동, 날짜 선택
- 진행률: 선택한 날짜의 전체 진행률과 카테고리별 진행률
- 미완료 항목을 다음 날로 이월
- `localStorage`에 자동 저장 (새로고침·브라우저 재시작 후에도 유지)

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 정적 서버로 여는 방법이 가장 확실합니다.

```bash
python -m http.server 8000
```

실행 후 `http://localhost:8000/index.html`로 접속합니다.

> 스크립트를 ES 모듈이 아닌 일반 `<script>`로 불러서 `index.html`을 더블클릭(`file://`)해도 동작하도록 만들었지만, 개발 중 검증은 로컬 서버에서 했습니다.

## 테스트

Node나 별도 도구 없이 브라우저에서 실행합니다. 서버를 띄운 뒤 `http://localhost:8000/tests/index.html`을 열고, 탭 제목이 `PASS n/n`이면 통과입니다. 실패하면 페이지에 실패한 항목이 표시됩니다.

테스트 대상은 DOM과 무관한 순수 로직(날짜 처리, 할 일 추가·수정·삭제, 진행률 계산, 이월)과 저장소(버전 확인, 손상 데이터 복구)입니다.

## 프로젝트 구조

```
index.html        마크업과 스크립트 로드 순서
style.css         레이아웃, 카테고리 색상, 반응형
src/
  state.js        순수 로직 (날짜, CRUD, 조회, 진행률, 이월)
  storage.js      localStorage 입출력, 버전·손상 처리
  view.js         DOM 렌더링과 이벤트 연결
  app.js          상태 보관, 핸들러 구현, 저장 후 재렌더링
tests/            브라우저에서 실행하는 단위 테스트
docs/
  PRD.md          제품 요구사항
  superpowers/plans/   구현 계획
```

데이터 흐름은 사용자 이벤트 → 상태 변경 → 저장 → 재렌더링의 단방향입니다.

## 데이터와 저장

- 저장 위치: 브라우저 `localStorage`의 `todo-app:v1` 키, 형식은 `{ "version": 1, "todos": [...] }`
- 저장된 데이터가 손상되면 앱은 빈 상태로 시작하고, 원본은 `todo-app:v1:corrupt` 키에 백업한 뒤 화면에 안내를 표시합니다.
- 브라우저 저장소를 쓸 수 없거나 저장에 실패하면 화면에 안내를 표시합니다.
- 데이터는 사용 중인 브라우저와 주소(origin)마다 따로 저장됩니다. 다른 브라우저나 다른 주소에서는 보이지 않습니다.

## 지원 환경

최신 Chrome / Edge / Firefox / Safari, 화면 폭 360px 이상.

## 범위 밖

로그인, 서버·클라우드 동기화, 알림, 반복 일정, 우선순위, 태그, 다크모드, 내보내기/가져오기는 포함하지 않습니다. 자세한 내용은 [PRD](docs/PRD.md)를 참고하세요.
